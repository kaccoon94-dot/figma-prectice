## 1. 링크
- **Live Demo** : https://kaccoon94-dot.github.io/figma-prectice/
- **GitHub** : https://github.com/kaccoon94-dot/figma-prectice
- **Figma 디자인** : https://www.figma.com/design/JjCVeUo7AVTkKV2S1sc2uk/%EA%B5%AD%EB%A6%BD%EB%8C%80%EC%A0%84%ED%98%84%EC%B6%A9%EC%9B%90%EA%B0%9C%EC%84%A0?node-id=334-4004&t=mzy7E3u1bn94zGmy-1

## 2. 프로잭트 정보
- **제작 기간** : 2026.11.06 ~ 2026.11.10 (5일)
- **담당 역할** : 개인 프로젝트 (기여도 100%)
- **담당 범위** : Figma 개선 디자인 → 바이브코딩 구현 → GitHub Pages 배포

## 3. 사용기술

- **React, Vite** : [웹 상의 화면을 컴포넌트로 구성하여 편집하기 쉽게하기 위해 사용]
- **GitHub** : 페이지 배포를 위해 사용
- **Figma** : 디자인 개선을 위해 사용
- **Claude** : 바이브 코딩으로 화면 구현을 위해 사용

## 4. 주요 기능

- [기능 1: 메인 화면에서 이용안내 버튼을 누르면 한번에 전체적인 이용안내 페이지로 이동 가능]
- [기능 2: 메인화면의 밀집화된 정보들을 정리해주는 화면 레이아웃 재구성]

## 5. 트러블슈팅

### 이슈 : [이용안내 버튼을 사용한 페이지 이동 불가]

- **문제** : [상단의 메인 메뉴를 통한 페이지 이동은 가능 했으나, 메인 화면의 이용안내 버튼을 이용한 페이지 이동이 안되었음]
- **원인** : [버튼의 이동 주소가 `#`로 들어가 있었음]
- **해결** : [버튼 주소를 `/guide`로 연결]

## 6. AI 활용 방식

### 1. 컴포넌트 구현
- **맡긴 일** : Figma 컴포넌트(버튼, 카드, 메뉴, 검색 등)를 디자인 토큰만 사용해 React 컴포넌트로 구현
- **핵심 프롬프트** : "[Figma 링크] 이 섹션의 컴포넌트들도 button과 같은 방식으로 만들어줘. 의존성 관계를 고려해서 순서대로 만들어줘. 이름을 figma와 같게 하고 토큰만 사용해."

### 2. 반응형 처리
- **맡긴 일** : 완성한 모바일 화면을 태블릿/데스크탑 시안에 맞게 확장
- **핵심 프롬프트** : "모바일은 완성했고, 태블릿/데스크탑 시안은 이 링크야. [Figma 링크] 모바일 스타일은 유지하고, 시안과 똑같이 만들어줘."

### 3. 페이지 연결
- **맡긴 일** : 빠진 화면을 찾아 만들고, 메인 화면 버튼과 각 페이지를 연결
- **핵심 프롬프트** : "[Figma 링크] 빠진 페이지들 체크해서 만들어줘"

### 4. 배포
- **맡긴 일** : GitHub Pages 자동 배포 설정
- **핵심 프롬프트** : "이 vite React 프로젝트를 Github Pages로 배포할꺼야."

## 7. 회고

- **배운 점** : [Figma에서 색상·글자·컴포넌트 이름을 체계적으로 정리하니, AI가 코드로 옮길 때 그대로 이어져 디자인과 실제 화면의 매우 같았다. 디자인 단계에서 정리를 얼마나 잘 하느냐에 따라 결과물이 많이 달라진다라는 것을 배웠다.]
- **아쉬운 점** : [맨 처음 페이지와 버튼 연결을 신경 쓰지 않아, 이동 안되는 버튼을 찾아 이동 되게 끔 연결을 다시 해주어야했다.]
