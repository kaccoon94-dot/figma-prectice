## 2. 브랜드

### 컬러

피그마 변수에서 가져온 값입니다. 용도는 영상 기준 제안입니다.

| 이름 (피그마 변수) | HEX | 용도 |
|---|---|---|
| 대표 남색 `primary` / `blue/200` | `#283981` | 강조 텍스트, 선택 탭, 엔딩 배경 |
| 진한 남색 `blue/300` | `#003963` | 남색 배경의 보조·그림자 톤 |
| 포인트 파랑 `button01` | `#526FEE` | 검색어 하이라이트, 누름 표시 |
| 연한 파랑 `blue/50` / `button02` | `#EEF3F9` | 탭 배경, 강조 박스 배경 |
| 기본 글자 `colors/text/black` | `#222222` | 본문 자막 |
| 보조 글자 `gray/500` | `#666666` | 작은 설명 |
| 연한 글자 `colors/text/Secondary` | `#BBBBBB` | 비활성 텍스트 |
| 구분선 `gray/100` / `border01` | `#DDDDDD` / `#C6C6C6` | 선, 테두리 |
| 밝은 회색 `gray/50` | `#F3F3F3` | 보조 배경 |
| 흰색 `colors/bg/white` | `#FFFFFF` | 기본 배경, 남색 위 글자 |
| 빨강 `red/100` | `#ED1A3B` | 사용 안 함 (추모 톤과 맞지 않음) |

| 피그마 스타일 | 원본 크기 / 줄높이 | 영상 크기 (× 3) | 용도 |
