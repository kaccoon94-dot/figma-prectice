## 1. 사용자

### 작업자 (이 프로젝트를 만드는 사람)
- **코딩 초보자**가 Claude와 함께 만드는 서비스입니다.
- 설명은 쉬운 한국어로, 전문 용어는 처음 나올 때 한 줄로 풀어서 설명합니다.
- 한 번에 많은 것을 바꾸지 말고, **작은 단위로 나눠서** 진행하고 단계마다 무엇을 했는지 알려줍니다.
- 코드를 작성하거나 고친 뒤에는 **무엇을, 왜 바꿨는지**와 결과를 확인하는 방법(예: `npm run dev` 후 브라우저 확인)을 함께 안내합니다.
- **모르거나 애매한 부분은 추측하지 말고 먼저 질문합니다.** (요구사항, 문구, 디자인 값, 동작 방식 등)

### 서비스 이용자 (타겟 사용자)
모든 화면은 아래 두 사용자가 막힘 없이 쓸 수 있어야 합니다.

|---|---|---|
| 김순자 님 (72세) | 고령, 저시력·색약 유가족. 화면을 확대(200%)해서 봄 | 셔틀버스 시간표, 참배 유의사항 확인 |

## 2. 기술스택 (변경 금지)

> 아래 기술스택은 **변경하지 않습니다.** 다른 라이브러리·프레임워크가 필요해 보이면 설치하기 전에 반드시 먼저 물어봅니다.

| 구분 | 사용 기술 | 사용하지 않는 것 |
|---|---|---|
| 프레임워크 | React 19 | Next.js 등 다른 프레임워크 |
| 빌드 도구 | Vite 8 | CRA, Webpack 직접 설정 |
| 언어 | JavaScript (`.jsx`, `.js`) | TypeScript |
| 스타일 | 순수 CSS (`.css` 파일) | Tailwind, SCSS, styled-components 등 CSS-in-JS |
| 린트 | oxlint | ESLint 추가 설치 |
| 패키지 매니저 | npm | yarn, pnpm |

### 명령어
```bash
npm run dev      # 개발 서버 실행 (브라우저에서 확인)
npm run build    # 배포용 빌드
npm run lint     # 코드 검사
npm run preview  # 빌드 결과 미리보기
```

## 3. 디자인 규칙

### 디자인 구현 방식
- 화면 디자인은 **Figma MCP를 통해 구현**합니다. Figma에 없는 디자인을 임의로 만들지 않습니다.
- 구현할 화면의 Figma 링크는 작업자가 전달합니다. 링크가 없거나 디자인이 불분명하면 **먼저 질문**합니다.
- Figma 파일: `국립대전현충원개선` (fileKey `JjCVeUo7AVTkKV2S1sc2uk`)
  - `3-2.디자인_시스템` — 색상·글자 변수, 텍스트 스타일
  - `3-3.컴포넌트` — 아이콘·로고·UI 컴포넌트
  - `3-4.완성화면` — 모바일(360) / 데스크탑(1280) 완성 화면
  - `핸드오프문서` — 개발자용 토큰·컴포넌트·화면 명세

### 디자인 토큰
- 색상·간격·글자 크기는 코드에 직접 숫자를 쓰지 말고 `src/styles/tokens.css`의 CSS 변수를 사용합니다.
- 폰트: Pretendard GOV (Regular 400 / SemiBold 600)
  - 로컬 파일 `src/fonts/PretendardGOV-Regular.otf`, `PretendardGOV-SemiBold.otf`를 `src/styles/fonts.css`의 `@font-face`로 불러옵니다. (CDN 사용 안 함)
  - Bold(700) 파일은 없으므로 `font-weight: 700`은 사용하지 않습니다. 필요하면 먼저 질문합니다.
- 주요 색상: Primary `#283981` · 기본 텍스트 `#222222` · 보조 배경 `#EEF3F9` · 푸터 배경 `#F3F3F3` · 로고 `#003963` / `#ED1A3B`

### 반응형
| 구분 | 범위 | 적용 레이아웃 |
|---|---|---|
| 모바일 | 360px ~ 767px | 모바일 레이아웃 |
| 태블릿 | 768px ~ 1279px | 모바일 레이아웃 (화면 폭에 맞춰 늘려서 사용) |
| 데스크탑 | 1280px ~ | 데스크탑 레이아웃 |

- 레이아웃 전환은 **1280px 한 지점**에서만 일어납니다. 360px 미만은 지원하지 않습니다.
- **모바일 우선**: 기본 스타일은 모바일 기준, 데스크탑은 `@media (min-width: 1280px)`로 확장합니다. 미디어쿼리 값은 px로 씁니다.
- **단위**
  - 레이아웃은 상대단위(%, rem)를 쓰고, 고정 px 너비는 피합니다.
  - **em은 사용하지 않습니다.**
  - rem 기준은 루트 16px(브라우저 기본값)입니다. `html`에 px 폰트 크기를 고정하지 않습니다.
- **레이아웃**: 데스크탑 콘텐츠 영역은 rem 단위 `max-width` + 가운데 정렬, 배경은 화면 전체 폭. 최대 너비는 데스크탑 Figma 기준.
- **글자 크기**: rem으로 지정, 모바일/데스크탑별 크기는 Figma 기준.
- **내비게이션**: 모바일은 햄버거 메뉴, 데스크탑은 가로 메뉴바.
- **이미지·영상**: 기본 `max-width: 100%; height: auto;`, 비율 유지가 필요하면 `aspect-ratio`.
- **터치 영역**: 모바일에서 버튼·링크는 최소 `2.75rem × 2.75rem`(약 44px), 인접 요소 사이에 충분한 간격.
- 이 규칙과 Figma가 다르면 **Figma 우선**. 단, 단위 규칙은 항상 유지합니다.

### 접근성 (KWCAG 2.2 — 법적 의무, 반드시 지킴)
- **본문 바로가기**: 문서 최상단 첫 요소로 제공, Tab 1회로 나타남
- **자동 슬라이드**: 정지·재생, 이전·다음 버튼 필수. 자동 전환 때 키보드 초점이 사라지면 안 됨
- **대체 텍스트**: 의미 있는 이미지는 구체적인 `alt` ("이미지1" 금지), 꾸밈용 이미지는 `alt=""`
- **글자를 이미지로 만들지 않기**: 안내문·유의사항은 HTML 텍스트로 (200% 확대 시 깨짐 없음)
- **색에만 의존하지 않기**: 중요 정보는 색 + 기호(*, ⚠️) + 텍스트를 함께 사용
- **명도 대비**: 글자와 배경은 4.5:1 이상
- **레이블**: 입력칸은 `<label for>` 연결, 아이콘만 있는 버튼은 `aria-label`
- **변하는 결과 안내**: 검색 결과 등은 `aria-live="polite"` (예: "검색 결과 총 1건이 조회되었습니다.")
- **표**: `<table>`에 `<caption>`, `<thead>`, `<th scope>` 사용, 표 제목과 내용 일치
- **키보드**: 모든 기능은 키보드로 사용 가능, 포커스 표시(`:focus-visible`) 유지, 코드 순서 = 화면 순서
- **일관성**: 같은 대상은 어디서나 같은 이름·같은 위치로 표시

## 4. 서비스 구조

### 우선순위
| 등급 | 내용 |
|---|---|
| **P0** | 메인 화면 밀집 완화 + 웹 접근성 보장 |
| **P1** | 민원·신청 창구 통합, 신청서 작성 과정 개선 |
| **P2** | 방문·참배 정보 한곳에 모으기 (통이미지 → HTML 텍스트/표) |
| **P3** | 메뉴 체계·용어 통일 (GNB 3단계 드롭다운) |

### 메뉴 구조 (GNB)
1. 방문·참배 2. 민원·신청 3. 현충원 소식 4. 현충원 소개
- 의견·문의 창구는 하나로 통합해 GNB에 노출합니다.

### 주요 화면
**① 메인 홈**
- 순서: 본문 바로가기 → 공식 전자정부 배너 → 헤더(로고 · 글자/화면 확대 · 언어 변경(국기 미사용) · 로그인) → GNB → 히어로 캐러셀 → 3대 핵심 서비스 → 푸터
- 캐러셀 컨트롤(좌측 하단): `[정지/재생] [이전] [1/3] [다음]`
- 3대 핵심 서비스: 방문·참배 원스톱 / 민원·신청 통합 / 안장자·묘역 찾기(검색폼)
- 바로가기 9개 → 3개 그룹으로 축소, 과도한 배너·QR 제거
- 푸터: 개인정보처리방침(강조) | 이용약관 | 오시는 길 | 대표전화 042-822-0026

**② 방문·참배 원스톱 안내**
- 제목 `<h1>방문·참배 원스톱 안내</h1>`, 탭: 보훈모시미(셔틀) 운행안내 / 방문 유의사항 / 경내 지도
- 셔틀 시간표는 데이터 표, 예외 운행 안내는 기호 + 텍스트 박스
- 유의사항은 HTML 목록(`<ul>`)

**③ 안장묘역 위치 검색 및 편의시설 안내**
- 제목 `<h1>안장묘역 위치 검색 및 편의시설 안내</h1>`
- 검색폼(`<label for>` + `aria-label` 검색 버튼), 결과 영역 `aria-live="polite"` + 결과 표
- 교통약자 편의시설(휠체어 대여소, 장애인 전용주차)은 텍스트/표로 제공

### 용어 규칙
- 셔틀버스 이름은 **'보훈모시미'**로 통일 ('참배객모시미' 사용 금지)
- '역사'와 '연혁' 메뉴를 중복으로 만들지 않고, 행정 용어 대신 쉬운 말 사용
- 메인 바로가기 이름 = 실제 페이지 이름 = 사이트맵 이름
- 신청서의 '전체 동의'는 맨 위에 배치, 입력은 단계별로 나눔

### 폴더 구조
```
docs/            # PRD.md(기획서), CLAUDE.md(작업 지침)
src/
├─ main.jsx      # 시작 파일
├─ App.jsx / App.css
├─ components/   # 재사용 컴포넌트 (필요할 때 생성)
├─ pages/        # 화면 단위 컴포넌트 (필요할 때 생성)
├─ assets/       # 이미지·아이콘 (필요할 때 생성)
├─ fonts/        # Pretendard GOV 폰트 파일 (Regular, SemiBold)
└─ styles/
   ├─ index.css  # 불러오는 순서: fonts → tokens → reset → global
   ├─ fonts.css  # @font-face 선언 (src/fonts 파일 사용)
   ├─ tokens.css # 디자인 토큰
   ├─ reset.css
   └─ global.css # 전역 스타일, 본문 바로가기, sr-only, 포커스 표시
```

## 5. 안전규칙

- **애매하면 질문**: 요구사항·문구·디자인이 불분명하면 추측하지 말고 먼저 물어봅니다.
- **기술스택 고정**: 2번의 기술스택을 바꾸지 않습니다. 새 패키지 설치(`npm install ...`)는 반드시 먼저 허락을 받습니다.
- **삭제·덮어쓰기 주의**: 파일·폴더를 지우거나 크게 바꾸기 전에 무엇이 바뀌는지 설명하고 확인을 받습니다.
- **`docs/` 문서 보호**: `PRD.md`, `CLAUDE.md`는 요청이 있을 때만 수정합니다.
- **범위 지키기**: 요청받은 작업만 합니다. 추가로 고치면 좋을 부분은 직접 바꾸지 말고 제안만 합니다.
- **작업 후 확인**: 코드를 바꾼 뒤에는 `npm run lint`와 `npm run build`로 오류가 없는지 확인하고 결과를 알려줍니다.
- **Figma 수정 금지**: Figma MCP는 디자인을 **읽는 용도**로만 사용합니다. Figma 파일 수정은 요청이 있을 때만 합니다.
- **민감 정보 금지**: 비밀번호, API 키, 개인정보(안장자 실명 등 실제 데이터)를 코드에 넣지 않습니다. 예시 데이터는 '홍길동'처럼 가상의 값을 씁니다.
- **git 작업**: 커밋·푸시 등 git 작업은 요청이 있을 때만 합니다.
